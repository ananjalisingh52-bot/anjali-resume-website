# Anjali Singh | Personal Resume Website

A macOS-inspired personal resume website built with **HTML and CSS** for the Web Development mid-term project (IIM Bangalore, BBA in Digital Business and Entrepreneurship).

## About
Anjali Singh is a BBA student at IIM Bangalore who runs an agency helping founders and coaches build their personal brand on Instagram through authority content and organic lead generation.

## Features
- macOS-style menu bar and a bottom Dock for navigation
- Every section styled as a Mac window with traffic-light buttons
- Sky blue and white palette using CSS variables, frosted-glass effect, animated gradient background
- Skills marquee, stats widgets, hover animations
- Fully responsive (works on mobile)

## Sections
Home, About, Skills, Experience and Projects, Goals, Contact

## CSS concepts used
- **Selectors:** element (`body`, `h1`), class (`.window`, `.card`), ID (`#menubar`, `#dock`)
- **Display and positioning:** flexbox, grid, `position: sticky` and `fixed`, `inline-block`
- **Fonts:** Inter (Google Fonts)
- **Colours:** CSS variables in `:root`
- **Extras:** `backdrop-filter`, keyframe animations, media queries
